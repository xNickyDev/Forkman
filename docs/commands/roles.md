# /roles

Returns all existing roles.

## Usage

```
/roles {page}
```

## Arguments

| Name  | Description                      | Type   | Required |
| :---: | :------------------------------: | :----: | :------: |
| page  | The number of the page.          | Number | No       |
| event | Filter by the event of the role. | Enum   | No       |

### Possibilities

<!-- tabs:start -->

#### **event**

- `Halloween` - Filters roles by Halloween event.
- `Christmas` - Filters roles by Christmas event.
- `New Year` - Filters roles by New Year event.
- `Valentine` - Filters roles by Valentine event.
- `Birthday` - Filters roles by Birthday event.
- `April Fools` - Filters roles by April Fools event.
- `Easter` - Filters roles by Easter event.
- `Wizard of Oz` - Filters roles by Wizard of Oz event.
- `Hex Fest` - Filters roles by Hex Fest event.
- `Moon Festival` - Filters roles by Moon Festival event.
- `Any` - Filters roles by Any event.
